Problem Statement & Motivation
EV Battery Safety & Thermal Runaway
02 / 12

Industrial Challenge

  • Thermal Runaway Risks: Exothermic decomposition in Li-ion cells accelerates rapidly above 65°C, causing fires within seconds.
  • Cell Imbalance: Slight manufacturing variations in capacity and internal resistance cause cells in series to drift in voltage.
  • Premature Capacity Cutoff: The weakest cell limits the entire pack's range during charge and discharge.

Our Solution Architecture

  • Microsecond Precision: Kernel character driver simulating cell electrochemistry with 200ms deterministic timer ticks.
  • Derivative Temperature Gradient: Rate-of-rise ($dT/dt$) tracking to detect runaway before physical fire occurs.
  • Active Safety Loop: POSIX message queues and shared memory sequence locks for instant contactor tripping.

Kernel Space Implementation
Linux Character Driver (bms_driver.c)
04 / 12

Interrupt-Safe Timer

Uses struct timer_list rescheduled via mod_timer every 200ms. Runs in atomic/softirq context.

Synchronized using spin_lock_irqsave() to prevent races between timer updates and userspace IOCTLs.

IOCTL Control Interface

Exposes 6 commands using _IOR, _IOW, and _IOWR:

  • GET_PACK_DATA: Full pack telemetry
  • INJECT_FAULT: Inject OV/UV/OT
  • CLEAR_FAULTS: Reset state
  • SET_BALANCE_MODE: 0/1/2

Diagnostic Procfs

Creates /proc/bms_status using the kernel seq_file interface.

Outputs formatted ASCII tables showing per-cell voltage, temperature, SoC, state, and active fault bitmasks without allocating kernel buffers.

Core Algorithms
Coulomb Counting SoC Estimation
05 / 12

Mathematical Model

$$SoC(t) = SoC(0) - \frac{1}{Q_{nominal}} \int_{0}^{t} I(\tau) \, d\tau$$

  • Current Sign Convention: Positive current $I > 0$ indicates discharge (SoC decreases); negative current $I < 0$ indicates regen/charging.
  • Euler Discretization: $\Delta Q = I \times \Delta t$ [Ampere-seconds].
  • Clamping: Bounded cleanly in $[0.0, 100.0]\%$ to prevent sensor noise windup.

Implementation in C++

float SoCCalculator::update(float current_A, float dt_s) {
    // Integrate net charge consumed
    charge_used_as_ += current_A * dt_s;

    // Compute updated percentage
    float delta_soc = (charge_used_as_ / capacity_as_) * 100.0f;
    soc_pct_ = std::clamp(soc_initial_ - delta_soc, 
                          0.0f, 100.0f);
    return soc_pct_;
}

Thermal Runaway Early Detection (dT/dt)

Gradient Runaway Criterion

CRITICAL: (T > 65°C) AND (dT/dt > 5.0°C / min)

Calculated using backward difference:

dT/dt = (T_current - T_previous) / dt × 60

4-Stage Health Hierarchy:

NORMAL (≤45°C) WARM (≤55°C) HOT (≤65°C) CRITICAL

Passive Cell Balancing Controller
07 / 12

Dissipative Shunt Balancing

  • Target Voltage ($V_{min}$): Identifies the lowest healthy cell voltage across the string.
  • Imbalance Threshold: Activates when $\Delta V = V_{cell} - V_{min} > 50\text{ mV}$.
  • Bleed Current ($I_{bleed}$): Simulates 500 mA current draw through bypass MOSFET & resistor.
  • Energy Accounting: Measures total energy dissipated as heat: $\Delta E = V \cdot I \cdot \Delta t$ [Joules].

Balancing Logic (C++)

uint8_t CellBalancer::checkBalance(const BatteryCell cells[], 
                                   size_t count) {
    float min_v = getMinHealthyVoltage(cells, count);
    uint8_t mask = 0;

    for (size_t i = 0; i < count; ++i) {
        if (cells[i].voltage_V > (min_v + 0.050f)) {
            mask |= (1u << i); // Flag cell for bypass
        }
    }
    balance_mask_ = mask;
    return mask;
}

C++ Templates & Lock-Free IPC

MovingAverage<T, N> Template

Filters ADC sensor noise using an $O(1)$ running sum:

template<typename T, std::size_t N>
class MovingAverage {
    std::array<T, N> buffer_{};
    std::size_t head_ = 0, count_ = 0;
    T sum_ = T{0};
public:
    void push(T val) {
        sum_ -= buffer_[head_];
        buffer_[head_] = val;
        sum_ += val;
        head_ = (head_ + 1) % N;
        if (count_ < N) count_++;
    }
    T average() const { return count_ ? sum_ / count_ : T{0}; }
};

POSIX Shared Memory & Seqlock

  • Shared Memory Region: /bms_shm created via shm_open and mmap.
  • Seqlock Algorithm:
    • Writer sets sequence to ODD before writing.
    • Writer updates telemetry struct in shared memory.
    • Writer increments sequence to EVEN when done.
    • Reader retries if sequence was ODD or changed.
  • POSIX Message Queue: /bms_alerts sends asynchronous, high-priority notifications.

Automated Safety Response

  • Reaction Latency: Daemon detects anomaly in ≤ 200 ms.
  • Emergency Broadcast: Pushes CRITICAL message to /bms_alerts queue.
  • State Isolation: Flags cell state as CRITICAL and commands contactor disconnect.
  • Persistent Audit: Timestamped incident recorded in /var/log/bms/bms_data.csv.
